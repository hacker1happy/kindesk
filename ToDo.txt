### Admin Features
* Add/remove/manage Admins, Ops Team Members, and Callers.
* Export all client data along with associated case details in excel format.
* Access performance dashboards for Ops Team Members and Callers:
  * Active clients
  * Closed cases
  * Pending cases
  * Clients added by callers
  * Filters for daily, weekly, monthly, and custom date ranges.
* Bulk reassignment feature:
  * Reassign clients/tasks/cases from one employee to another when someone leaves the organization.
  * Applicable for both Callers and Ops Team Members.
- edit master companies+rta details

### Ops Team Member Features
* Add new companies and RTAs if they do not already exist:
  * Company name and address
  * RTA name and address
* View clients assigned by callers (`assigned_from`).
* Edit client details assigned to them.
* Create new clients.
* Manage and process case-related workflows.

### Caller Features
* Add new clients.
* View and edit client details added by them.
* Upload client documents.
* No permission to create or modify cases.
